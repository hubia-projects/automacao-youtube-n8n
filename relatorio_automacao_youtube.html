03Relatório: O Que Está Mal no Seu Vídeo
  • 🔴 CRÍTICO — Matching semântico não funciona O maior problema. O algoritmo está buscando clipes por keywords superficiais (ex: "Portugal" → pega tudo sobre Portugal sem filtrar por relevância com o trecho específico do roteiro). Resultado: imagens genéricas e desconexas.
  • 🔴 CRÍTICO — Repetição de clipes A barraca de comida de rua aparece por quase 40 segundos, representando a maior parte do vídeo. O sistema não está detectando nem evitando repetição de clipes já usados.
  • 🔴 CRÍTICO — Nenhuma imagem gerada por IA Sem geração de IA (Midjourney/Runway/Sora), é impossível criar cenas específicas ao tema. Stock footage genérico nunca vai casar perfeitamente com um roteiro específico. Esse é o maior gap em relação ao referência.
  • 🟠 GRAVE — Ausência de pós-produção Sem música de fundo, o vídeo soa "vazio" e amateur. Sem títulos/textos on-screen, o conteúdo perde impacto visual. Sem transições, os cortes parecem bugs.
  • 🟠 GRAVE — Indexação temporal por segmento de áudio não funciona Os clipes não estão sendo selecionados frame-a-frame com base no conteúdo narrado naquele exato segundo. A lógica de matching precisa ser por unidade de sentença/frase, não por tema geral do vídeo.
  • 🟡 MODERADO — Clipes de baixa qualidade visual Frame 001 mostra um corredor muito escuro, quase ilegível. A etapa de seleção precisa filtrar por brilho médio, sharpness, ausência de artefatos.
  • 🟡 MODERADO — Transcrição das cenas insuficiente A descrição gerada pelo Gemini para cada mini-trecho provavelmente está genérica demais (ex: "pessoas caminhando") para permitir matching preciso com o roteiro.
  • 🟡 MODERADO — Vídeo muito curto 2:41min é muito curto para conteúdo documental/informativo. O algoritmo está "ficando sem clipes" e repetindo os poucos que encontrou.

01

Geração de Tema + Roteiro Estruturado Manter

Continua com Gemini/OpenAI. Melhoria: o roteiro deve ser entregue em JSON estruturado com: { "block_id": 1, "text": "...", "duration_estimate": 5, "visual_type": "specific|generic", "visual_description": "jovens anos 2000 usando Orkut no Brasil", "keywords": ["orkut", "social media", "2000s"] }. O campo visual_type é crucial para decidir entre gerar IA ou buscar stock.

02

TTS com Timestamps Word-by-Word Melhorar

Multivozes_br_engine está OK, mas verifique se entrega timestamps por palavra. Se não, use ElevenLabs API (mais preciso) ou force-align com Whisper forced alignment (WhisperX). Você PRECISA saber exatamente quando cada palavra é dita para sincronizar os clipes.

03

Geração de Imagens/Vídeos com IA NOVO — CRÍTICO

Para todos os blocos marcados como visual_type: "specific", gere imagens/vídeos com IA. Opções: Imagens estáticas → DALL-E 3 API ou Ideogram (melhores resultados para cenas humanas). Clipes curtos → Runway Gen-3, Kling AI, ou Pika. Ken Burns Effect → aplicar movimento nas imagens estáticas via ffmpeg (zoom + pan). Isso resolve o problema fundamental de não encontrar stock específico.

04

Busca de Stock com Embedding Semântico CORRIGIR URGENTE

Para blocos visual_type: "generic". Abandone busca por keywords simples. Use CLIP (OpenAI): encode a descrição textual de cada bloco do roteiro como embedding vetorial → encode thumbnails dos clipes → calcule cosine similarity → pegue os top-5 mais similares. Bibliotecas: openai/clip-vit-base-patch32 via HuggingFace. Isso vai mudar completamente a qualidade do matching.

05

Corte e Etiquetagem de Mini-trechos (com Qualidade) CORRIGIR URGENTE

Na transcrição de cenas com Gemini Vision, force descrições detalhadas com prompt específico: "Descreva em 1 frase o que acontece nessa cena incluindo: ambiente, pessoas, ação, época, humor/tom visual. Depois liste 5 tags relevantes." Adicione filtros de qualidade: brilho médio > 40, sharpness score > threshold, sem clipes escuros ou borrados. Adicione hash perceptual para detectar e eliminar clipes duplicados/muito similares antes de usar.

06

Montagem por Segmento de Áudio CORRIGIR URGENTE

Quebre o áudio em segmentos de 3-7 segundos (por pausa natural na fala). Para cada segmento: (1) pegue o texto sendo narrado, (2) use CLIP para encontrar o clipe com maior similaridade a esse texto, (3) use o clipe com offset aleatório dentro do trecho disponível. Mantenha uma lista de used_clips e nunca repita o mesmo clipe. Se não encontrar clipe adequado → use imagem gerada por IA com Ken Burns.

07

Música de Fundo + Mixagem NOVO

Adicionar trilha sonora muda COMPLETAMENTE a percepção de qualidade. Use Pixabay Music API ou EpidemicSound para buscar música por mood (dramático, reflexivo, etc.) compatível com o tema. Mixar com ffmpeg: narração em volume 100%, música em 8-12%. Adicionar fade-in no início e fade-out no final.

08

Títulos, Textos On-Screen e Transições NOVO

Gere títulos automáticos com IA (momentos-chave do roteiro) e renderize com ffmpeg drawtext. Adicione crossfade de 0.3s entre cada clipe. Aplique color grading consistente (LUT) em todos os clipes para uniformizar o visual. Isso elimina o "choque visual" entre clipes de fontes diferentes.

09

QA Automatizado Antes do Upload NOVO

Antes de subir ao YouTube, rode uma checagem: (1) detectar clipes repetidos via hash, (2) verificar sincronização áudio-vídeo, (3) checar se há segmentos de silêncio ou frames pretos, (4) checar duração mínima (>8 min para monetização). Só sobe se passar em todos os checks.

⚠️ Resumo das Prioridades

Prioridade 1 (faz mais diferença imediata): Implementar geração de imagens com DALL-E/Runway para cenas específicas + CLIP para matching semântico de stock.

Prioridade 2: Adicionar música de fundo e transições crossfade — impacto na percepção de qualidade é enorme com pouco esforço.

Prioridade 3: Sistema de deduplicação de clipes para eliminar repetições + filtros de qualidade visual nos clipes selecionados.
